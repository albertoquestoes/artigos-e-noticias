Resumo sobre Sistemas Operacionais, Pastas e Offices (Windows 10)

Dicas para ConcursosInformática
Os Sistemas Operacionais são programas ou um conjunto de programas criados para gerenciar os recursos do computador (inclusive outros programas ativos em paralelo) e prover uma interface entre a máquina e usuário. O funcionamento do sistema operacional ocorre com a iniciação de procedimentos essenciais ao bom funcionamento do computador, como atualizações ou processamentos de dados. É possível acessar e acompanhar os procedimentos do sistema operacional no Gerenciador de Tarefas. Também é possível aferir a quantidade de memória utilizada em cada processo, ou se algum deles está causando problemas ao computador. Há muitos sistemas operacionais no mercado, mas o mais conhecido e utilizado é o Windows, desenvolvido pela Microsoft e constituinte de uma família de versões de sistemas operacionais. Vamos falar um pouco a seguir sobre o Windows 10, apesar do 11 já estar disponível. 

Windows: o mais famoso dos sistemas operacionais

O Windows 11, até o momento em que editamos este artigo, é a versão mais recente do Sistema Operacional da Microsoft. Ele trouxe uma série de modificações e novidades, como em toda versão lançada. Como ele não é o objetivo deste artigo, trataremos ainda da versão Windows 10, que contempla um maior número de computadores pelo mundo. Entre as mudanças trazidas pelo Windows 10, as que mais se destacam são:
  • Proposta de uma plataforma padrão para notebooks, desktops, tablets e smartphones;
  • Retorno do Menu Iniciar;
  • Múltiplas áreas de trabalho;
  • Novo e exclusivo navegador: o Microsoft Edge, com modo leitura e opção de fazer anotações à caneta nas páginas.

Configurações básicas

Se você tem interesse em atualizar seu Windows para o Windows 10, existem alguns requisitos mínimos necessários de hardware:
  • Sistema operacional mais recente: última versão do Windows 7 SP1 ou do Windows 8.1 Update;
  • Processador: 1 gigahertz (GHz) ou mais rápido ou SoC;
  • Memória RAM: 1 gigabyte (GB) para 32 bits ou 2 GB para 64 bits
  • Espaço em disco rígido: 16 GB para um SO de 32 bits ou 20 GB para um SO de 64 bits;
  • Placa gráfica: DirectX 9 ou posterior com driver WDDM 1.0;
  • Tela: 800x600.
Mas, se seu interesse for sair do Windows 10 para o Windows 11, infelizmente, é bem provável que terá que trocar de computador. Os requisitos da versão 11 são bem mais exigentes.

Interface

A interface do Windows 10, por exemplo, possui especificidades de acordo com o dispositivo que você utiliza. O menu Iniciar consta em todas as suas versões, mas em dispositivos com touchscreen, vem com uma coluna à esquerda da tela que disponibiliza atalhos. Caso o dispositivo seja híbrido, o usuário pode ativar teclado ou touch. Há também uma nova área de trabalho virtual que abre todas as janelas em uso e permite alternar e encaixar como quiser, ou mesmo mover para outra área de trabalho.

Sistemas operacionais: painel de controle

O Windows 10 desenvolveu um painel de controle adequado para uso em dispositivos com touchscreen, mas ainda não disponibiliza todas as possibilidades das versões mais antigas. Você pode, no entanto, encontrar essas opções no Painel de Controle Clássico do Windows 10:Basta clicar com o botão direito do mouse no canto inferior esquerdo da tela (sobre o botão Iniciar) e depois, ao surgir o menu, clicar em “Painel de Controle”. O Painel de Controle antigo do Windows será aberto e você pode criar um atalho para tornar o acesso mais prático.

Pastas e arquivos

Um dos grandes trunfos do Windows é o sistema simples e prático de criação de pastas para organização de arquivos. Você pode criar no programa Windows Explorer quantas pastas e subpastas precisar e organizar nelas todo tipo de arquivos (textos, áudios, vídeos, planilhas, imagens, etc.). O Windows Explorer torna o acesso a essas pastas e arquivos muito simples: basta localizar uma pasta desejada em um dos diretórios e dar um clique duplo. O programa irá abrir a pasta em uma nova janela e irá expor todos os arquivos que nela constam. Você ainda pode mover arquivos de uma para outra, copiar ou deletar.

Offices: Writer e Word

Ao se tratar de sistemas operacionais, não podemos esquecer dos aplicativos. Writer e Word, por exemplo, são processadores de textos muito conhecidos e utilizados, tanto por empresas (escritórios) como em residências. O Writer tem funções similares às do Word, mas apresenta algumas diferenças, como as combinações das teclas de atalho. Entre outras diferenças, temos:
  • O Word é um editor de texto desenvolvido pela Microsoft. Portanto, é um programa pago e que demanda licença de uso. O Writer é um editor de texto gratuito distribuído por diferentes organizações, sendo as mais conhecidas LibreOffice Writer e OpenOffice Writer;
  • O Writer possui no menu arquivo o comando Exportar para PDF, mas esta opção só ficou disponível no Word a partir da versão 2010;
  • Existem apenas dois modos de exibição no Writer que são Layout de Impressão e Layout da Web, no Word existem vários.

Sistemas operacionais: aplicativos Calc e Excel

Já com relação a planilhas de cálculos temos o Excel, da Microsoft, e o Calc da suíte OpenOffice (também pelo BrOffice e LibreOffice). Os dois programas têm aparência semelhantes, mas, assim como Word e Writer, possuem algumas diferenças, como onúmero de colunas das planilhas. O Calc possui 1.024 colunas, enquanto no Excel o número varia de acordo com a versão (256 na versão de 2003, mas 16.384 na versão de 2007). Por outro lado, fórmulas e funções basicamente apresentam o mesmo comportamento. Por exemplo, ao editar uma na célula A1 a fórmula =B1+C1 e usar a alça de preenchimento para baixo, as células seguintes serão preenchidas com =B2+C2. Entre os usuários de planilhas, o consenso geral é de que a planilha do Excel possui recursos mais completos.
